# 华为耳机连接时自动切换 Mac 输出

用户已确认安装：HUAWEI FreeBuds Pro 5 连接时将系统默认媒体输出切到耳机，
断开后恢复连接前可用的输出；连接期间手动改选输出则保留该选择，直到下次重连。

使用 Swift/CoreAudio 读取可用输出、监听设备列表和默认输出变化。
按耳机精确名称匹配，以 CoreAudio UID 保存恢复设备，不依赖运行期间可能变化的设备 ID。
只改默认媒体输出，不修改输入、音量、播放器播放状态或其他项目服务。
事件去抖配合低频补查处理设备就绪延迟与睡眠唤醒，切换错误限次重试并记录日志。

独立用户级 LaunchAgent `com.zhangyichi.headphone-output` 登录启动；程序、状态、日志
安装至内置盘 `~/Library/Application Support/XiaoaiAudioSwitch`，源码保存在当前项目。
无新网络服务、管理员权限或第三方依赖。用户可随时停用或卸载。

验证分为状态转换测试、真实 CoreAudio 枚举、LaunchAgent 常驻检查和实际耳机重连测试。
耳机尚未连接时，只能确认服务待命，不能宣称真实切换和耳机出声已验证。

实现步骤：编写独立状态机与音频适配层；编译并测试边界；安装 LaunchAgent；
检查状态并让用户重连耳机验证；补充交接文档、白名单提交并尝试推送核对远端 SHA。

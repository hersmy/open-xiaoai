# 代码在线点歌与退下

用户确认补齐“本地未找到 → 网易云在线搜索播放”，明确禁止 computer use，要求“退下”也不调用 Agent。
采用标准库 HTTP 请求搜索元数据，再用 Mac 网易云注册的 orpheus 原生 URL 播放；不用界面点击、浏览器、
独立 API 服务或音乐下载，不读取/复制网易云或 Harness 凭据。客户端自行处理登录和会员权限。

本地文件匹配优先，已有 NCM 原样交给网易云；仅明确歌曲的本地未命中才走联网搜索。
明确“本地”限制的请求不联网。按真实歌手字段和歌名严格匹配，不把标题中的“原唱”当歌手；
同名不同歌手要求补充歌手。相同歌手同名的多个发行版本可选首个可用版本，不隐式替换为 Live/翻唱。
翻唱返回的 originSongSimpleData 可用于查原唱详情，仍须检查原唱自身权限；不可播、未找到、超时均固定报错。
在线请求有超时和响应大小限制，不调用 Agent 重试。原生 URL 仅包含验证过的正整数歌曲 ID。

桥接保留“收到 → 代码 → 已完成”，沿用原生 AIVS/PNS 并行恢复。在线结果含 source 和阶段计时，
打开成功仅为系统接受请求，不等同每次已经出声或有全曲权限。在线曲目替换本机曲目指针，防止后续
本地上一首/下一首使用旧位置；目前在线切歌不接管客户端播放列表，会提示先点播本地歌曲。

“退下/退下吧/你退下吧”按精确句子匹配，不拦截“退下是什么意思”等问题。
仅在自定义唤醒窗口或最近控制上下文接管，先清理收音计时器、回声重开麦和待执行控制，
原声回应一次“收到”，恢复原生前端后回到待唤醒。不调用 Agent，不停音乐，不删除会话历史。
已交给播放器的动作不撤销；原生恢复期间的输入保持排队，避免切断下一轮收音。

验证包括本地优先、明确本地未命中不联网、原唱/翻唱/版本/同名歧义、不可播、超时、打开失败、
无凭据请求、原生 URL 参数、在线曲目不会留下旧本地切歌位置，以及退下后无超时提醒且须重新唤醒。
纯代码调用《有何不可》已由用户确认播放成功；《枫》原唱详情已实测 st=-200、播放地址为空，须如实提醒。
